# Требования к проекту "Домашняя Бухгалтерия"

## 1. Общее описание

**Цель проекта:** Веб-приложение для учёта личных финансов с AI-распознаванием скриншотов банковских приложений.

**Целевая аудитория:** Пользователи, которые хотят отслеживать свои расходы, загружая скриншоты из мобильных банковских приложений.

## 5. Модель данных

### 5.1 Транзакция (Transaction)

| id | Integer | Да (auto) | Уникальный идентификатор |

| description | String(500) | Да | Описание (название магазина) |

## 7. Пользовательские сценарии

### UC-001: Добавление транзакции через скриншот

**Актор:** Пользователь

**Предусловия:** Пользователь имеет скриншот из банковского приложения

**Основной сценарий:**
1. Пользователь открывает страницу "Загрузить"
2. Пользователь перетаскивает скриншот в зону загрузки
3. Система отправляет изображение на распознавание
4. Система показывает распознанные данные с уровнем уверенности
5. Пользователь проверяет и при необходимости корректирует данные
6. Пользователь нажимает "Сохранить"
7. Система сохраняет транзакцию и показывает подтверждение

**Альтернативный сценарий:**
- 4a. Если уверенность < 80%, система предупреждает пользователя
- 5a. Пользователь может отменить и загрузить другой скриншот

### UC-002: Просмотр отчёта за месяц

**Актор:** Пользователь

**Основной сценарий:**
1. Пользователь открывает страницу "Отчёты"
2. Система показывает отчёт за текущий месяц
3. Пользователь видит общую сумму, количество транзакций, средний чек
4. Пользователь видит график расходов по месяцам
5. Пользователь видит круговую диаграмму по категориям
6. Пользователь может выбрать другой месяц из выпадающего списка
